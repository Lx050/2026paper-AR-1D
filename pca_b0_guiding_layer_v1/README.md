# PCA-B0 Guiding Layer v1

This package adds the missing guidance layer above the 5 weekly experiment runbooks.

Start here:
1. `PCA_B0_guiding_charter_v1.pdf` - full readable charter.
2. `traceability_matrix_v1.csv` - maps doctrine to experiment evidence.
3. `weekly_alignment_checklist_v1.csv` - use before each weekly runbook.
4. `risk_register_guiding_layer_v1.csv` - keep updated during experiments.
5. `glossary_v1.csv` - controlled vocabulary.

Core doctrine:
Good output = Core Consistency Gate + Perceptual Activation Ranking.

Operational rule:
Every script, dataset, scorer, and weekly action must answer: does it help preserve user-valued invariants, or does it help rank perceptual activation after invariants are preserved?

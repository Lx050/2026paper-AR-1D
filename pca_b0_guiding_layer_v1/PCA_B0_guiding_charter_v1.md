# PCA-B0 总纲：感知激活-一致性基线的指导层

版本：v1.0  
用途：统领 5 周实验包的“指导层 / 宪法层 / 判断层”。  
一句话：**先保住用户最不想失去的核心不变量，再在合格候选中选择最能激活用户感知、记忆、情绪和偏好的输出。**

---

## 0. 为什么需要总纲

前面的 5 周 runbook 已经解决了“任务层”和“行动层”：每周做什么、怎么装环境、怎么跑 scorer、怎么做人类标注、怎么写报告。

但它们缺一个更高层的问题：

> **所有这些动作到底服从什么共同意志？**

本总纲回答的不是“怎么跑脚本”，而是：

1. 我们到底在研究什么；
2. 什么算好输出；
3. 什么算失败；
4. 指标和人类判断冲突时听谁；
5. 一致性、偏好、情绪、记忆、文化之间如何排序；
6. 每周实验如何回到总问题，而不是散成工具堆。

---

## 1. 总命题

当前 AIGC 常把目标写成：图像更真实、更美、更像参考、更符合 prompt。

本项目改写目标：

> **AIGC 输出不是照片本身，而是可被用户感知并激活其记忆、情绪、审美和意义联想的显示信号。**

因此我们不以“照片真实度”为最终目标，也不以“参考图像素相似度”为最终目标，而以：

\[
\text{Good Output} = \text{Core Consistency Gate} + \text{Perceptual Activation Ranking}
\]

换成中文：

> **先过核心一致性门槛，再做感知激活排序。**

---

## 2. 三层目标

### 2.1 第一层：显像层

输出必须能被当前硬件、屏幕、投影或显示设备承载。

这意味着“图像”只是可显示信号的一种，不必局限于照片。未来它可以是图像、视频、shader、3D、点云、光场、AR 或别的可感知信号。

第一阶段为了可实验，先落在文生图 / 参考图生成上。

### 2.2 第二层：一致性层

用户给参考图，通常不是要求机械复制，而是说：

> 这里面有我已经认可的核心价值，请不要丢掉。

所以参考图不是复制模板，而是价值锚点。

一致性不是“所有东西都不变”，而是：

> **用户最不希望失去的核心不变量没有丢。**

这些核心不变量可能是：主体身份、轮廓、亲切感、城市烟火气、文化符号、空间关系、数量、文字、构图节奏、情绪氛围。

### 2.3 第三层：激活层

通过一致性门控后，才比较哪张图更能激活用户。

激活不是情绪标签本身，而是：

> 图像在用户脑中激活了什么记忆、审美、文化经验、意义联想。

第一阶段只能用公开数据近似：情绪、记忆性、人群偏好、文化语境。个人记忆层需要小规模用户自采数据补上。

## 3. 核心公式

### 3.1 输入

每个任务写作：

\[
T = (p, r, u, c, I, V, C, K)
\]

其中：

- \(p\)：prompt / 用户语言意图；
- \(r\)：reference / 参考图或参考主体；
- \(u\)：user / 用户偏好与历史；
- \(c\)：context / 文化、地域、使用场景；
- \(I\)：invariants / 必须保持的不变量；
- \(V\)：variants / 允许变化的变量；
- \(C\)：constraints / 任务约束；
- \(K\)：budget / 成本预算。

### 3.2 一致性门控

\[
\text{Accept}(y) = 1[ C_{subject}(y,r) \land C_{structure}(y,p) \land C_{forbidden-loss}(y,u) ]
\]

候选 \(y\) 只有先通过核心一致性门控，才允许进入后续排序。

### 3.3 感知激活排序

\[
\text{Rank}(y) = \alpha R_{pref}(y) + \beta R_{emotion}(y) + \gamma R_{memory}(y) + \delta R_{culture}(y,c)
\]

第一版权重可以手动设定，不急着训练：

- \(\alpha\)：人群偏好；
- \(\beta\)：情绪/氛围激活；
- \(\gamma\)：记忆性；
- \(\delta\)：文化/地域适配。

### 3.4 最终输出

\[
y^* = \arg\max_{y \in \{y: \text{Accept}(y)=1\}} \text{Rank}(y)
\]

如果没有候选通过门控，不强行输出“最漂亮”的错误图，而是记录失败类型。

## 4. 十二条指导原则

### 原则 1：参考图不是模板，而是价值锚点

不能把参考图简单理解为“要复制的像素”。参考图代表用户已经确认过的好东西。

### 原则 2：一致性是门槛，不是终点

一致性用于防止核心价值丢失；通过门槛后，允许创造性偏离。

### 原则 3：偏离不一定是错

如果偏离保留了核心价值，而且用户认为更好，则该偏离是可接受甚至有益的。

### 原则 4：感知激活高于照片真实

照片真实只是历史阶段的稳定输出形式。真正目标是用户脑中的意义激活。

### 原则 5：指标是证据，不是裁判

CLIP、ImageReward、EmotionCLIP、MemNet、GenEval 都只是观察工具。最终必须用人类小样本验证指标是否可信。

### 原则 6：残差不是失败定义

失败不是分数低，而是在给定不变量、允许变化和当前可调手段下，系统不能生成满足约束的输出。

### 原则 7：不可吸收是相对概念

不可吸收相对于模型、可调手段、成本预算和约束成立。换一个系统或加一个结构变量，失败可能被吸收。

### 原则 8：先分型，再修复

不要一失败就加模块。先判断是搜索失败、表示缺失、耦合缺失、任务欠定还是约束冲突。

### 原则 9：文化不是装饰，而是背景变量

同一个视觉符号在不同地域、收入、生活经验中可能激活不同意义。因此文化/地域数据不是锦上添花，而是背景建模的一部分。

### 原则 10：数据集服务于定义，不反过来支配定义

不要因为某个数据集有现成标签，就把问题改成它能测的东西。先保持理论定义，再选择或改造数据。

### 原则 11：每个实验都必须能失败

如果结果无论如何都能解释为成功，这不是科研。每个实验要写清楚什么结果会削弱我们的主张。

### 原则 12：保持局部、条件性、可验证

不宣称“所有 AIGC 失败都来自阻碍”，不宣称“PCA-B0 是最终审美模型”，不宣称“自动理解个人记忆”。

## 5. 核心概念字典

| 概念 | 定义 | 在实验中的表现 |
|---|---|---|
| 显示信号 | 用户可看到/感知的输出载体 | 图像、视频、3D、shader，第一阶段为图像 |
| 参考图 | 用户偏好与主体结构的联合锚点 | reference image |
| 核心不变量 | 用户最不希望失去的东西 | identity、shape、关系、情绪、文化符号 |
| 允许变化 | 用户允许系统重构的部分 | 姿态、背景、风格、服装、构图 |
| 核心损失 | 生成结果丢掉用户最在意的部分 | core-loss / forbidden-loss |
| 感知激活 | 输出在用户脑中触发的情绪、记忆、联想 | emotion、memorability、activation words |
| 一致性门控 | 先剔除核心不变量崩坏的候选 | Accept(y) |
| 激活排序 | 在合格候选里选择最能触发目标感知的输出 | Rank(y) |
| 可吸收失败 | 可通过补充变量/介入方式修复的失败 | retry、rewrite、layout、reference、verifier |
| 不可吸收失败 | 当前系统和预算下无法修复的失败 | 任务冲突、底座能力不足、缺关键证据 |

## 6. 指导层如何统领 5 周任务

### Week 1：资源清算

指导问题：这些资源分别支持总纲里的哪一层？

- EmoSet / ArtEmis：情绪与意义解释；
- LaMem / MemNet：记忆性；
- ImageReward / PickScore / HPS：人群偏好；
- DreamBench++ / VBench：主体一致性；
- T2I-CompBench / GenEval / RelTR：结构关系；
- GeoDE / Dollar Street / DIG-In：文化地域背景。

Week 1 的成果不是“下载很多资源”，而是完成资源到理论层的映射表。

### Week 2：跑通评分器

指导问题：每个 scorer 对应的是门控还是排序？

- 门控：主体、结构、禁止损失；
- 排序：偏好、情绪、记忆、文化。

严禁把排序分数拿来覆盖门控失败。例如，一张图再好看，只要主体核心崩了，就不能进入激活排序。

### Week 3：搭 pipeline

指导问题：pipeline 是否体现了“先门控，后排序”？

必须对比：

- preference-only；
- consistency-only；
- PCA-B0 gate + rank。

要证明旧 baseline 为什么不够：只偏好会丢核心，只一致会无激活。

### Week 4：做人类小样本

指导问题：我们的自动分数是否真的接近用户判断？

必须问用户：

1. 哪张更喜欢？
2. 哪张保住了参考里最好的部分？
3. 哪张偏离是可接受的？
4. 哪张丢掉了最不能丢的东西？
5. 它让你想到什么？

### Week 5：写报告

指导问题：结果支持还是削弱总纲？

必须诚实写：

- 哪些 scorer 不可靠；
- 哪些任务 PCA-B0 不比普通偏好强；
- 哪些一致性门槛太硬；
- 个人记忆层仍缺什么数据。

## 7. 决策规则

### 7.1 当“偏好分数高”但“主体一致性低”

判定：不合格。

理由：核心价值先于激活排序。

### 7.2 当“主体一致性高”但“用户不喜欢”

判定：通过门控但排序失败。

处理：保留为 consistency-only 失败案例，说明一致性不是终点。

### 7.3 当“自动指标高”但“用户拒绝”

判定：指标失真。

处理：将样本加入 evaluator failure set，检查文化、个人偏好、参考理解是否缺失。

### 7.4 当“偏离参考”但“用户更喜欢”

判定：可能是成功。

前提：核心不变量没有丢，用户确认偏离可接受。

### 7.5 当“所有候选都不过门控”

判定：候选生成能力不足或任务约束太强。

处理：进入失败吸收阶梯：retry、rewrite、matched augmentation、oracle。

### 7.6 当“人类也无法判断”

判定：任务欠定或约束冲突。

处理：请求补充说明，不强行输出。

---

## 8. 失败分型

| 类型 | 定义 | 例子 | 下一步 |
|---|---|---|---|
| F1 任务欠定 | 用户没给足核心不变量 | same cat 但无参考 | 请求补充 / 多解输出 |
| F2 不变量错误 | 系统不知道什么该变 | 锁死全部像素导致僵硬 | 分离 invariant / variant |
| F3 表示缺失 | 任务变量不在表示中 | 数量、空间关系错 | 加 object slot / relation graph |
| F4 耦合缺失 | 有变量但没进生成过程 | scene graph 只进 prompt | layout / attention / denoising coupling |
| F5 搜索失败 | 解存在但没采到 | 多 seed 可成功 | retry / rerank |
| F6 约束冲突 | 任务本身不可满足 | 两只猫但三只围圈 | 暴露冲突 |
| F7 底座能力不足 | oracle 也失败 | 完美 layout 仍画不出 | 换模型 / 训练 / adapter |

## 9. 实验验收标准

### 9.1 最小成功

在 50-100 条 pilot task 中，PCA-B0 至少展示：

1. 比 preference-only 更少 core-loss；
2. 比 consistency-only 更高 human win-rate；
3. 能识别至少两类 evaluator failure；
4. 能形成可复现数据表。

### 9.2 强成功

在两个以上任务类型中：

\[
\text{HumanWin}(\text{PCA-B0}) > \text{HumanWin}(\text{Preference-only})
\]

且：

\[
\text{CoreLoss}(\text{PCA-B0}) < \text{CoreLoss}(\text{Preference-only})
\]

### 9.3 失败条件

以下任意情况都必须诚实写入报告：

- PCA-B0 不优于 preference-only；
- 一致性门控过滤掉了用户喜欢的创造性输出；
- 情绪/记忆分数和用户激活词不相关；
- 文化/地域模块没有解释力；
- 自动 evaluator 与人类判断严重冲突。

## 11. 风险边界

### 11.1 不做的事

- 不从零训练生成模型；
- 不宣称自动理解个人记忆；
- 不宣称 PCA-B0 是审美真理；
- 不用一个总分覆盖所有维度；
- 不把参考相似度等同于用户满意；
- 不把情绪标签等同于感知激活。

### 11.2 必须谨慎表达的事

- “感知激活”第一版只是代理测量；
- “个人记忆”只能通过小样本用户数据近似；
- “文化适配”第一阶段只能用公开地域数据粗略支持；
- “一致性”必须按任务定义，而不是统一固定阈值。

## 12. 总纲放在项目里的位置

本总纲是最高层文档。

文档层级如下：

1. **指导层**：本总纲，决定原则和判断顺序；
2. **任务层**：5 周 runbook，决定每周做什么；
3. **行动层**：脚本、命令、数据表，决定怎么执行；
4. **证据层**：输出、评分、人类标注，决定结果是否成立；
5. **写作层**：pilot report 和 paper outline，决定如何发表。

任何行动层变化都必须回到指导层检查：

> 它是否服务于“先核心一致性，后感知激活”？

如果不是，暂时不做。

## 13. 挂在墙上的一句话

> **我们不是让图像更像照片，而是让输出更准确地保留用户认可的核心价值，并激活用户真正想要的感知经验。**
